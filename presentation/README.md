## 主题：

介绍本项目中的IGO求解器及其应用

## 核心内容
1. 介绍IGO求解器的工作原理，从问题背景到算法细节。（算法部分主要是流程图，公式之类的可以简略一点，IGO的部分可以参考 [README_IGO.md](../README_IGO.md)）
2. 用可视化的方式展示IGO求解器在求最优解的过程中是如何迭代更新搜索分布的，以及如何逐步逼近最优解的。（在文件夹[output_igo_test](../output_igo_test)中有一些示例图片和视频，[README_IGO.md](../README_IGO.md)也对图片做了说明，可以参考一下）
3. 介绍IGO求解器在实际应用中的效果和优势，主要针对cost的设计方法。cost的设计是通过 逆最优控制（inverse optimal control）的方法来实现的，可以参考 [README_IGO.md](../README_IOC.md) 中的内容。同时用了一个 双轮差速驱动 机器人（differential drive ）作为示例，有一个程序可以做展示（这个程序不要放在presentation里，而是写一页内容，我到时候直接运行给大家看）。
